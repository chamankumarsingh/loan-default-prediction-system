# 🏦 DefaultGuard Pro – AI Loan Default Prediction System

An AI-powered Loan Default Prediction System built using **FastAPI, React, TypeScript, Scikit-Learn, SQLite, SQLAlchemy, and JWT Authentication**. The platform helps financial institutions assess loan default risk using Machine Learning while providing an interactive dashboard, customer management, analytics, and reporting.

# ⚡ Installation

## Clone Repository

```bash
git clone https://github.com/chamankumarsingh/loan-default-prediction-system.git
```

## Backend

```bash
cd backend

python -m venv venv

source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run server

```bash
uvicorn app.main:app --reload
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
