# Database Schema & ER Diagram - Loan Default Prediction System

The system uses an SQLite database managed with the SQLAlchemy Object Relational Mapper. Below is the database entity schema.

## 2. Table Definitions

### Table: `users`
Represents the system operators (employees) who log into the dashboard.
- `id` (INTEGER, Primary Key): Unique identifier.
- `username` (VARCHAR, Unique, Indexed): User account name.
- `email` (VARCHAR, Unique, Indexed): User email.
- `password_hash` (VARCHAR): Hashed password.
- `role` (VARCHAR): Assigned role (`Admin`, `Manager`, `Analyst`, `Viewer`).
- `is_active` (BOOLEAN): Active status indicator.
- `created_at` (DATETIME): Timestamp when user was created.

### Table: `customers`
Stores demographic and general profile info for credit applicants.
- `id` (INTEGER, Primary Key): Unique identifier.
- `first_name` (VARCHAR)
- `last_name` (VARCHAR)
- `email` (VARCHAR, Unique, Indexed)
- `phone` (VARCHAR)
- `age` (INTEGER)
- `gender` (VARCHAR)
- `education` (VARCHAR)
- `marital_status` (VARCHAR)
- `employment_type` (VARCHAR)
- `job_experience` (INTEGER)
- `annual_income` (FLOAT)
- `monthly_income` (FLOAT): Derived as `annual_income / 12`.
- `home_ownership` (VARCHAR)
- `created_at` (DATETIME)
- `updated_at` (DATETIME)

### Table: `loans`
Represents loan applications submitted for risk analysis.
- `id` (INTEGER, Primary Key)
- `customer_id` (INTEGER, Foreign Key referencing `customers.id`)
- `loan_amount` (FLOAT)
- `loan_term` (INTEGER): Duration in months.
- `credit_score` (INTEGER): FICO range (300 to 850).
- `existing_loans` (INTEGER): Active loans count.
- `debt_to_income_ratio` (FLOAT): Derived DTI.
- `number_of_dependents` (INTEGER)
- `loan_purpose` (VARCHAR)
- `previous_defaults` (INTEGER)
- `savings_balance` (FLOAT)
- `current_balance` (FLOAT)
- `emi` (FLOAT): Calculated EMI amount.
- `status` (VARCHAR): Underwriting status (`Pending`, `Approved`, `Rejected`, `Defaulted`).
- `created_at` (DATETIME)

### Table: `predictions`
Saves risk evaluations generated by the machine learning engine.
- `id` (INTEGER, Primary Key)
- `customer_id` (INTEGER, Foreign Key referencing `customers.id`)
- `loan_id` (INTEGER, Foreign Key referencing `loans.id`)
- `risk_probability` (FLOAT): Value between 0.0 and 1.0.
- `risk_rating` (VARCHAR): Risk classification (`Low`, `Medium`, `High`).
- `confidence_score` (FLOAT): Assessment confidence percentage.
- `explanation_json` (TEXT): JSON dump storing calculated feature attributions.
- `created_at` (DATETIME)
- `created_by_id` (INTEGER, Foreign Key referencing `users.id`)

### Table: `audit_logs`
Tracks critical security actions performed in the backend.
- `id` (INTEGER, Primary Key)
- `user_id` (INTEGER, Foreign Key referencing `users.id`)
- `action` (VARCHAR): Trigger action.
- `details` (TEXT): Descriptive details.
- `created_at` (DATETIME)
